# floc website

Statische marketingsite (HTML/CSS/JS, geen build-stap) voor bezoekers en festivals.

## Starten

```sh
cd website
python3 -m http.server 4321
```

Open **http://localhost:4321**.

## Bestanden

| Bestand | Inhoud |
|---|---|
| `index.html` | alle secties en teksten |
| `styles.css` | huisstijl: zelfde kleuren als de app (`Floc/Theme.swift`) |
| `script.js` | menu, scroll-animaties, pilotformulier (nog zonder backend) |
| `img/app-*.jpg` | echte screenshots uit de iOS-app (iPhone 16-simulator, kaart `wildenburg2026-v2`) |
| `img/dashboard-map.jpg` | echte kaartlagen (paden, open velden, water, bos, voorzieningen) over de PDOK-luchtfoto |
